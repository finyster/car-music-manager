# 重複歌曲過濾

GUI 0.5.0 預設啟用 **自動略過重複歌曲**。

## 判定層級

1. **相同 YouTube 影片 ID**：`music.youtube.com`、`youtube.com` 與 `youtu.be` 指向同一影片時視為相同來源。
2. **相同來源網址或本機路徑**：同一個來源重複加入時，載入階段直接略過。
3. **相同歌手、歌名與接近長度**：載入階段只有在長度相差 3 秒以內時才自動略過，降低把 Live、Remix 或不同演奏版本誤刪的風險。
4. **相同目的地曲目標籤**：開始處理時會掃描目的資料夾既有 MP3 的歌手與歌名。
5. **相同來源檔 SHA-256**：下載或讀取本機檔案後，內容完全相同就略過。
6. **持久索引**：成功輸出後，在目的資料夾寫入 `.car-music-dedupe.json`，下次執行仍可辨識已處理來源。

## GUI 狀態

重複項目會顯示：

```text
重複略過
```

將滑鼠移到狀態欄，可看到原因，例如：

- 相同來源已經處理過
- 目的資料夾已有相同歌手與歌名
- 來源檔案內容完全相同（SHA-256）

## 保留不同版本

需要保留相同歌名的 Live、Remix、鋼琴版或不同演奏版本時：

- 先確認 Title 包含 `Live`、`Remix`、`Piano Ver.` 等版本資訊；或
- 取消勾選 **自動略過重複歌曲**。

關閉此選項後仍會正常建立檔案，但成功項目仍會記錄到索引，供未來重新啟用時使用。

## 舊歌庫

0.5.0 會先掃描目的資料夾既有 MP3 的 Artist 與 Title，因此舊檔也能得到基本保護。來源網址與 SHA-256 索引則會從 0.5.0 成功處理的歌曲開始累積。
