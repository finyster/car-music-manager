# GUI MVP 範圍

目前版本著重於快速可用：

- 貼上多個一般 YouTube 網址、播放清單或頻道並讀取 metadata。
- 使用專用的「讀取 YouTube Music」流程處理歌曲、播放清單、專輯與藝人頻道。
- 匯入 TXT/CSV 連結。
- 加入本機音訊檔或整個資料夾。
- 表格勾選、搜尋、編輯歌手/歌名/專輯。
- 選擇目的資料夾並新增子資料夾。
- 遠端來源逐首確認「有權取得」。
- 使用既有 two-pass loudnorm 與安全發布流程。
- 可選共用封面，或逐首抓取 YouTube Music 圖片並轉成 500×500 JPEG。
- 依 YouTube ID、來源、歌手／歌名、來源檔 SHA-256 與持久索引過濾重複。
- 背景處理、進度、取消、單首失敗後繼續。
- 保存最後使用的輸出資料夾、視窗大小、自動封面與去重選項。

YouTube Music 專用流程會移除常見追蹤參數，並針對藝人頁、播放清單和專輯使用保守的 metadata fallback。它只負責讀取曲目資料，不會自動把版本確認視為下載授權。

去重功能預設啟用。相同 YouTube 影片與完全相同來源會直接略過；歌手、歌名相同且長度相差 3 秒內時才在載入階段視為同版本。處理完成後會在目的資料夾保存 `.car-music-dedupe.json`。需要保留 Live、Remix 或不同演奏版本時，可取消勾選去重或先補完整版本名稱。

後續版本可增加逐首封面預覽、SQLite 歷史、可編輯車機 Profile、音訊指紋與更完整的暫停/繼續。
