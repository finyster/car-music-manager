# GUI MVP 範圍

目前版本著重於快速可用：

- 貼上多個一般 YouTube 網址、播放清單或頻道並讀取 metadata。
- 使用專用的「讀取 YouTube Music」流程處理歌曲、播放清單、專輯與藝人頻道。
- 匯入 TXT/CSV 連結。
- 加入本機音訊檔或整個資料夾。
- 表格勾選、搜尋、編輯歌手/歌名/專輯。
- 選擇目的資料夾並新增子資料夾。
- 遠端來源逐首確認「有權取得」。
- 使用既有 two-pass loudnorm 與安全發布流程。
- 可選共用封面，轉成 JPEG 後嵌入 ID3v2.3。
- 背景處理、進度、取消、單首失敗後繼續。
- 保存最後使用的輸出資料夾與視窗大小。

YouTube Music 專用流程會移除常見追蹤參數，並針對藝人頁、播放清單和專輯使用保守的 metadata fallback。它只負責讀取曲目資料，不會自動把版本確認視為下載授權。

後續版本可增加逐首封面、SQLite 歷史、可編輯車機 Profile、縮圖預覽與更完整的暫停/繼續。
