# GUI 手動驗收清單

- [ ] `car-music-gui` 可啟動且沒有 traceback。
- [ ] 可貼上單一影片、播放清單及頻道網址。
- [ ] 可一次貼上多個網址。
- [ ] 可加入本機檔案與本機資料夾。
- [ ] 一般 YouTube 網址可由「讀取網址」載入 metadata。
- [ ] YouTube Music 歌曲網址可由「讀取 YouTube Music」載入。
- [ ] YouTube Music 播放清單／專輯網址可載入多首曲目。
- [ ] YouTube Music 藝人網址可透過 `/videos` metadata fallback 載入。
- [ ] `si` 追蹤參數不影響 YouTube Music 讀取。
- [ ] 非 `music.youtube.com` 網址在 YT Music 專用流程中會被安全略過。
- [ ] YT Music 列顯示來源、歌手、歌名、專輯、長度與頻道。
- [ ] YouTube Music 有圖片時，封面欄顯示「可自動抓取」。
- [ ] 開啟「自動抓取每首封面」後，輸出 MP3 會嵌入 500×500 JPEG APIC。
- [ ] 相同 YouTube 影片以 Music、一般 YouTube 與 youtu.be 網址重複加入時只保留一筆。
- [ ] 同一網址重複讀取時，狀態列顯示重複略過數量。
- [ ] 同歌手、同歌名且長度相差 3 秒內的項目會自動略過。
- [ ] 同一個本機檔案重複加入時只保留一筆。
- [ ] 來源檔 SHA-256 完全相同時，處理階段顯示「重複略過」。
- [ ] 重開 GUI 後，再處理相同來源時會讀取 `.car-music-dedupe.json` 並略過。
- [ ] 取消「自動略過重複歌曲」後，可刻意保留不同版本。
- [ ] 表格可以勾選、全選、全不選及搜尋。
- [ ] 歌手、歌名、專輯欄位可修改。
- [ ] 可選擇輸出目的地並新增子資料夾。
- [ ] 未確認授權的遠端列會被安全跳過。
- [ ] 本機來源能輸出 256 kbps / 44.1 kHz / Stereo MP3。
- [ ] 選擇 PNG/WEBP/JPEG 共用封面後，會優先於自動封面。
- [ ] 單首失敗時其他歌曲繼續。
- [ ] 取消後不再開始下一首。
- [ ] 重開程式後保留最後目的資料夾、封面與去重選項。
- [ ] `car-music verify <輸出資料夾>` 全部通過。
