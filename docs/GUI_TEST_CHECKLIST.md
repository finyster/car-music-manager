# GUI 手動驗收清單

- [ ] `car-music-gui` 可啟動且沒有 traceback。
- [ ] 可貼上單一影片、播放清單及頻道網址。
- [ ] 可一次貼上多個網址。
- [ ] 可加入本機檔案與本機資料夾。
- [ ] 表格可以勾選、全選、全不選及搜尋。
- [ ] 歌手、歌名、專輯欄位可修改。
- [ ] 可選擇輸出目的地並新增子資料夾。
- [ ] 未確認授權的遠端列會被安全跳過。
- [ ] 本機來源能輸出 256 kbps / 44.1 kHz / Stereo MP3。
- [ ] 選擇 PNG/WEBP/JPEG 封面後，輸出 MP3 包含 JPEG APIC。
- [ ] 單首失敗時其他歌曲繼續。
- [ ] 取消後不再開始下一首。
- [ ] 重開程式後保留最後目的資料夾。
- [ ] `car-music verify <輸出資料夾>` 全部通過。
